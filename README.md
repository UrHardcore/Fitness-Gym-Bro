📌 Visión General del Proyecto
Esta aplicación nace con el objetivo de ofrecer una solución integral, ágil y estructurada para el registro de sesiones de entrenamiento de fuerza y acondicionamiento físico. Pensada por y para deportistas, la plataforma busca eliminar las fricciones habituales al momento de anotar cargas, series y repeticiones en el gimnasio, reemplazando los métodos tradicionales por una interfaz intuitiva, moderna y optimizada para el uso en tiempo real.

El proyecto se encuentra actualmente en una etapa activa de diseño, estructuración de arquitectura y pruebas de rendimiento interno. La publicación de este repositorio cumple una función exclusivamente demostrativa y de control de versiones previo a su despliegue comercial e industrial.

🛠️ Características y Funcionalidades en Desarrollo
Gestión de Rutinas Personalizadas: Creación, edición y parametrización de bloques de entrenamiento según objetivos específicos (hipertrofia, fuerza máxima, RIR/RPE).

Registro de Cargas y Volúmenes: Seguimiento preciso de kilogramos levantados, repeticiones efectivas y tiempos de descanso entre series.

Historial y Análisis de Progreso: Visualización clara de métricas acumuladas a lo largo del tiempo para evaluar la sobrecarga progresiva.

Interfaz de Alta Eficiencia: Formularios y controles diseñados para minimizar la interacción táctil necesaria durante la sesión de entrenamiento.

📌 Project Overview
This application was created to provide a comprehensive, agile, and structured solution for tracking strength training and physical conditioning sessions. Built by and for athletes, the platform aims to eliminate the friction commonly associated with recording weights, sets, and repetitions in the gym, replacing traditional methods with an intuitive, modern interface optimized for real-time use.

The project is currently undergoing active design, architectural structuring, and internal performance testing. The publication of this repository serves a strictly demonstrative and version-control purpose prior to its commercial and public rollout.

🛠️ Key Features & System Specifications
Custom Routine Management: Creation, editing, and parameterization of training blocks tailored to specific goals (hypertrophy, maximum strength, RIR/RPE tracking).

Volume & Load Tracking: Precise monitoring of weight lifted, effective repetitions, and rest intervals between sets.

Progress Analytics & History: Clear visualization of accumulated metrics over time to evaluate progressive overload.

High-Efficiency User Interface: Input controls optimized to minimize necessary screen interactions during active workout sessions.
